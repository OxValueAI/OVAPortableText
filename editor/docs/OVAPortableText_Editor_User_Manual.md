# OVAPortableText 编辑器操作手册

这是本项目唯一的精简操作手册。

## 页面逻辑

- 左侧是层级导航：章节会展开，章节下面直接显示该章节的区块。
- 中间是焦点编辑区：点章节就编辑章节，点区块就编辑该区块内容或关联数据。
- 右侧是上下文信息：显示当前选中对象、路径、文档摘要、查找结果和本地版本。

推荐理解为：

```text
章节目录 -> 区块节点 -> 焦点编辑
```

## 顶部工具栏

- `Mode / 模式`：在可视化编辑和 JSON 源码之间切换。
- `File / 文件`：打开、复制、下载当前 JSON。
- `Search / 搜索`：输入关键词，结果显示在右侧查找结果。
- `History / 历史`：撤销或重做最近改动。
- `Output / 输出`：校验、最终预览、保存、保存本地版本。
- `Language / 语言`：切换 English / 中文界面。

## 常见操作

- 编辑章节标题：左侧点章节，中间修改 `Section Title / 章节标题`。
- 新增章节：左侧点任意章节，中间点 `Add Section / 添加章节`。
- 新增子章节：左侧点父章节，中间点 `Add Subsection / 添加子章节`。
- 新增段落：左侧点目标章节，中间点 `Add Paragraph / 添加段落`。
- 编辑正文：左侧展开章节并点击文本区块，中间文本框里修改。
- 编辑图表：左侧点击图表区块，中间会显示该区块关联的图表数据编辑器。
- 编辑表格：左侧点击表格区块，中间会显示该区块关联的表格单元格。
- 上移/下移区块：左侧点区块，中间点 `Move Block Up/Down / 上移区块/下移区块`；结果是该区块在当前章节内向上或向下换一个位置。
- 复制区块：左侧点区块，中间点 `Duplicate Block / 复制区块`，副本会出现在原区块后面。
- 删除区块：左侧点区块，中间点 `Delete Block / 删除区块`，只移除当前章节内的该区块。
- 校验问题：点顶部 `Validate / 校验`，问题列表显示在左侧 `Issues / 问题`。

## JSON 模式

- 点 `JSON` 进入源码编辑。
- 点 `Apply / 应用` 应用 JSON 修改。
- 点 `Discard / 放弃` 丢弃未应用的 JSON 草稿。
- JSON 草稿未应用或无效时，可视化编辑会锁定。
