## 冻结决定

1. 使用正式 chartType=valuation_result，复用 ChartBlock 和 grid 引用，不新增正文块。
2. 金额必须结构化，kind 为 point 或 range；货币基本单位与显示倍率明确分离。
3. 主体、币种、估值口径、基准日期和数据性质必填；投前/投后仅适用于股权价值。
4. 颜色、字号和边距由渲染器模板负责；三层横幅及语义显示要求是正式合同。
5. 不支持的渲染器必须明确失败；不将图片/普通文本回退声明为原生支持。
6. 历史同名自定义数据按原版本保留，升级时必须显式转换。
