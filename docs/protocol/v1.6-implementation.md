# v1.6 SDK 实现与渲染联调记录

日期：2026-10-13。SDK 发布版本：0.7.0；协议与 SDK 于本日冻结，见[冻结记录](v1.6-freeze.md)。渲染器当前无法测试，渲染与编辑器验收延期。默认 authoring 版本保留 report.v1.5，新能力显式选择 report.v1.6。

## 已实现的 SDK 范围

- PageSettings、ObjectPagination、CellAlignment、CaptionBinding 和 PageThemeConfig。
- 章节、正文对象、表格布局、列设置和文本 caption 的新增字段及构建入口。
- 新增字段的 null、枚举、作用位置、版本边界与修改后的重新校验。
- 显式 caption 的同内容流引用、前后各组邻接、多段、类型、重复 id 和非法位置检查。
- ContentItem 的显式分组解析、旧 figure 隐式关联兼容、DocumentResolver 显式目标解析。
- JSON 文件与字符串往返、旧协议/默认值回归；SDK 不计算物理分页，不执行渲染验收。

## SDK 验证结果

- 全部 326 项测试通过，包含 85 项 v1.6 新测试；旧 241 项回归通过。
- wheel/sdist 构建成功，twine 元数据检查通过。
- wheel 在独立虚拟环境中安装；仅复用本地已安装的运行时/测试依赖，不复制项目源码或 editable 安装，全部 326 项测试通过。
- 安装包环境下，使用指南代码及 v16_layout_report.py 运行通过；v1.6 JSON 往返有效，默认创建仍为 v1.5。
- 正式 0.7.0 wheel 在 Python 3.10 / Pydantic 2.12.5 及最低声明依赖 Pydantic 2.8.0 的独立环境中各通过全部 326 项测试。
- 新增模块/测试静态检查、文档链接和协议副本一致性检查通过。
- v1.5 冻结归档和 startup_report_example 原有文件保持不变。
