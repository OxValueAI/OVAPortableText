## 冻结范围与发布决定

本次冻结协议字段合同与 Python SDK。用户明确要求在开发测试通过后发布分支和 Python 包，并说明渲染器当前无法测试，因此本次不以渲染器测试作为发布阻塞条件。

这不是渲染验收通过声明。横纵向恢复、跨页表格、caption 同页边界、页码效果及编辑器组操作仍需下游独立验收；协议第 23.8 节的渲染要求保持不变。现有编辑器仍以 v1.3 为基线，不能据此宣称其支持 v1.6。

## 冻结决定

1. 分页与页面方向分离：正文 image/chart/table/figure 支持前后分页，page 只覆盖方向，不隐含独占页面。
2. 章节方向按树继承，实例方向包含关联 caption；以实际相邻内容决定必要的换页，不生成恢复方向的空白页。
3. 新增表级、列级和表头对齐默认值；保留已有单元格对齐、文本布局和必填列宽规则。不纳入 record 的 rowIndex 单元格覆盖。
4. caption 保留独立文本块，可显式绑定同内容流内的对象实例，前后各一个连续组；对象只产生一个编号。
5. 兼容既有 figure 隐式后置 caption；普通旧 caption 不自动重解释。新显式绑定支持更严格的邻接与类型校验。
6. SDK 默认仍创建 report.v1.5；使用新增字段必须显式选择 report.v1.6。旧版本不隐式升级，v1.5 归档和当前报告样例保持不变。
7. 不支持新能力的下游不能静默忽略相关约束后声称支持 v1.6。
